## 1. 功能区（按选项卡）

| Zotero 批注 | — | 把当前文档在 Zotero 里的批注（高亮 / 下划线 / 便签 / 文本框 / 区域 / 墨迹）导入这份 PDF，整批一次撤销；只读 Zotero 本机库（拷贝数据库快照再读，绝不写 Zotero），按文件路径对应到同一个附件。默认自动查找 Zotero 数据目录，找不到时让用户选一次并记住 |

| 撤销 / 重做 | Ctrl+Z / Ctrl+Y | 合并之后不可撤销（状态栏提示） |
| 选择 / 抓手 | — | 与批注工具同属一组互斥工具 |
| 搜索 | Ctrl+F | 右上角搜索浮层；F3 / Shift+F3 下一个 / 上一个 |

| --- | --- | --- |

| 下划线 | 拖拽选字，蓝色细线预览，松开提交 | 右键选中文字还可选：高亮 / 删除线 / 波浪线 |

| 便签 | 单击页面 → 输入内容 | |
| 文本框 | 单击页面 → 输入文字，文字直接显示在页面上 | 按文字量自动定大小（最宽 260pt 折行）；侧栏双击可改文字；中文 / 旋转页正常显示 |
| 橡皮擦 | 单击批注删除 | 点在空处提示「这里没有批注」 |
| 签名 | 手绘或选择图片 → 单击页面放置 | 放置完成或 Esc 后回到「选择」 |
| 时间 | 单击页面放置当前日期时间 | 同上 |

* 选中批注工具时，阅读区顶部出现提示胶囊（如「● 拖拽选字以高亮  Esc」）。
* 中文可**精确到字**选择与高亮。

### 1.6 AI 助读（可选的联网功能，默认关闭）

| 功能 | 入口 | 说明 |
| --- | --- | --- |
| AI 面板 | Ctrl+J / 「AI 面板」 | 右侧抽屉（默认 380px，宽度动画；拖左边缘调宽度 320–760，双击恢复默认，记住宽度）：预设动作、对话气泡（你的请求在右、AI 回答在左）、输入框（Enter 发送，Shift+Enter 换行） |
| 总结全文 | 面板 / 功能区 | 结构化总结：研究问题 / 方法 / 主要结果 / 局限 / 可借鉴之处；要点带 `[p.N]` |
| 推荐问题 | 面板 / 功能区 | AI 提出 5 个值得问的问题，点击即提问 |
| TL;DR 速览 | 面板「更多」/ 功能区「速读」 | 三句话以内概括问题 / 做法 / 结论，每句带 `[p.N]` |
| 速读高亮 | 面板「更多」/ 功能区「速读」 | 当前页按句编号发给 AI，AI 只回最该读的句子编号；在页面上标出（不改文件，缩放后仍在）。「存为批注」逐句转成高亮批注；换文档 / 增删页 / 旋转 / 清空对话时清除。扫描页需先 OCR 并另存才能定位 |
| 更多 ▾ | 面板 | 解释方法、列出贡献、找出局限、审稿意见、提炼术语 |
| 提问 | 面板输入框 | 短文整篇作为上下文；长文用 BM25 检索相关片段（外加开头）；保留最近 3 轮对话（翻译、解释、总结也算，可以接着追问） |
| 划词翻译浮窗 | 选中文字后选区末尾的「译」按钮 | 译文流式显示在选区下方的浮窗里（不进对话历史）：可复制、「在 AI 面板继续」（进对话，可追问）；标题栏可拖动，📌 钉住后点页面别处不收起，Esc / × 关闭。功能区「划词翻译」切换触发方式：显示「译」按钮（默认）/ 选中即翻译 / 关闭；只在 AI 助读已配置时出现 |
| 查词卡 | 选中单个英文单词后点「译」（或选中即译） | 本机离线词典（ECDICT 精简版，约 15 万词，不联网、不需要 AI）：单词、音标、释义、词形变化与考试标签；查的是变形时显示原形并注明（went → go 的过去式）。「收藏」加入单词本；「结合本句解释（AI）」让 AI 按所在句子解释（AI 已配置时）；词典没收录的词直接交给 AI |
| 连翻 | 浮窗 🔗 / 功能区「连翻」/ Ctrl+Shift+L | 接着选的文字拼在上一段后面整体翻译（跨栏 / 跨页断开的句子），浮窗显示「已拼接 N 段」；累计超过 4000 字从头开始；开关记在设置里 |
| 乱码检测 | 自动 | 选中的文字像乱码（私用区字形、替换符、几乎全是符号）时不发送，浮窗提示并提供「框选这段文字，截图识别后翻译」：视觉模型直接读图，否则本机 OCR 识别后再翻译 |
| 翻译 / 解释 | 右键选中文字、功能区 | 选中的原文折叠在请求气泡里（一行摘要 + 来源页与字数，点开看全文）；解释会附带所在段落作参考；「问 AI…」把选中文字作为引用卡片放在输入框上方，下一问针对它（可点 × 取消） |
| 框选提问 | 面板 / 功能区 | 拖框选取公式或图表：模型支持图片时发送截图，否则发送区域内的文字 |
| 发送前清洗 | 自动 | 选中文字发给 AI 前合并排版换行与行尾断词、展开连字（ﬁ → fi）、删去软连字符与零宽字符；普通复制也会展开连字 |

打开文档约 0.5 秒后，主线程会分片建立**全文文字索引**（每片约 20 ms，片间让出事件循环，只读、不改文件）；总结 / TL;DR / 提问 / 推荐问题直接用索引缓存，不必在界面线程一次性逐页取词。索引尚未完成时，全篇 AI 请求等待可取消的分片读取；内容变化后重新索引，失败会明确提示，不同步退回整篇取词。20 ms 为每片软预算，单个复杂页面仍可能超时。
| 回答排版 | 自动 | 中文语境的半角标点显示为全角；LaTeX 公式显示为 Unicode（O(n²)、√d、α、∑），行间公式居中；标题与要点配贴切的 emoji；复制 / 存批注用整理后的文本 |
| 页码引用 | 回答中的 `[p.N]` | 点击跳到该页（记入后退历史）；超出页数的页码不做成链接 |
| 存为批注 | 最后一条回答下方「存为批注」 | 最后一条回答存为便签：锚在选区 / 框选处，否则当前页左上角；内容以「【AI · 模型】」开头 |
| 扫描件 | 自动 | 文档没有文字层时提议 OCR 全部页；识别结果（本次会话、仅内存）直接代替扫描页的文字给 AI 用，不必另存；文档内容变化后作废 |
| 复制 / 停止 / 清空 | 回答下方「复制」/ 面板 | 每条回答都可复制；生成中发送键变为「停止」 |
| 模型设置 | 面板 ⚙ / 功能区 | 见下 |

**模型设置**：统一按 OpenAI Chat Completions 协议（`POST {Base URL}/chat/completions`，流式），
预设 DeepSeek、通义千问、Kimi、智谱、豆包、硅基流动、OpenAI、Gemini、OpenRouter、Anthropic、Ollama（本机）与自定义。
可「获取模型列表」（`GET /models`）、「测试连接」（失败原因译成中文：Key 无效、地址缺 `/v1`、额度不足、超时、代理 / 证书……）。
思考模型的推理内容（`reasoning_content` / `<think>`）不进入回答。

**隐私**：只有用户主动发起时才发送，且只发给配置的地址；首次向某个远程服务发送前确认（可勾「不再询问」），
本机地址不询问；加密 PDF 每次打开确认一次；单次超过 4 万字符提醒。API Key 存系统凭据管理器（Windows 凭据），不写入任何文件或日志。

标题栏右侧：浅色 / 深色切换、「关于」。

### 2.1 素材（写作素材库）

侧栏第四个页签「素材」：单词本 / 语料库 / 引文库 / 术语库，跨文档共用，存在本机 `%USERPROFILE%\.pdfreader\materials.db`。每条记下来源文档与页码：单击跳回原文（文档未打开会自动打开）；右键复制、编辑释义 / 备注、删除；可搜索；底部导出为 Markdown 或 CSV（CSV 带 BOM，Excel 直接打开）。单词从词卡的「收藏」加入；语料 / 引文 / 术语在选中文字的右键菜单里加入：

* **语料**：值得借鉴的原句，备注可写译文或心得；
* **引文**：原句 + 自动生成的转述起点「Previous studies have shown that …」，写综述时改写即可；
* **术语**：填写译名（最多 80 字的术语原文）。翻译（右键「AI 翻译」与划词翻译浮窗）时，原文出现了术语库里的术语，就把这些条目作为「术语表」附给模型，要求按你的译名翻译（整词匹配、不分大小写，一次最多 30 条）；功能区「划词翻译」下拉里可关闭「翻译时使用术语库」。

## 4. 搜索

Ctrl+F 打开右上角浮层，常驻显示当前文档名、全部页面和正文范围：输入即搜（停止输入 0.3 秒后开始，回车立即开始），显示「当前 / 总数」，结果列出
页码与命中所在整行（命中词加粗）；单击或 F3 / Shift+F3 定位并高亮命中位置。搜索在后台进行，换文档时自动作废。错误会清除旧结果；新查询即使快照失败，也不会重新接收上次查询或继续遍历旧命中。

## 5. 文件与会话

| 能力 | 说明 |
| --- | --- |
| 打开方式 | 菜单 / 文献库首页（导入、卡片、继续阅读）/ 标签栏「+」/ 拖放 / 双击 PDF / 「打开方式」/ 命令行 `PDFReader.exe 文件.pdf` |
| 文献库首页 | 没有文档时显示；阅读中点品牌「lumen.」或右上角网格按钮回来（文档保持打开，可「返回阅读」）。列出最近 40 个仍存在的文件：封面标题（PDF 标题或文件名）、作者、页数、批注数、阅读进度、上次打开时间；分区「全部 / 最近阅读 / 我的收藏 / 含批注文档」、按文件夹的合集与筛选、搜索（Ctrl+K）、按最近 / 名称排序、网格 / 列表视图（记住选择）、卡片星标收藏；「从上次的思考继续」打开最近一篇，「探索 AI 助读」打开文档并展开 AI 面板。首页显示时阅读器快捷键暂停（Ctrl+O 可用） |
| 最近文件 | 打开已不存在的文件时自动从列表移除 |
| 记住阅读位置 | 每个文件记住页、页内位置与缩放（最多 200 个），再次打开自动回到上次位置并提示 |
| 未保存提示 | 标题栏文件名后显示 `*`；关闭、切换文件、退出时询问 |
| 崩溃恢复 | 有未保存改动时每 60 秒把整份文档写到 `%USERPROFILE%\.pdfreader\recovery\`；异常退出后下次启动在文献库顶部提示，可「恢复 / 丢弃 / 稍后」。恢复前先备份原文件；原文件在崩溃后已变化或已删除时另存为恢复副本，不覆盖新内容。正常保存、撤销回干净状态或关闭文档后清理本次快照；未处理快照默认按 14 天、20 份、2 GB 预算清理旧项，原文件备份保留最近 5 份 |
| 会话恢复 | 正常退出时记住打开的标签顺序与当前标签，下次启动按顺序恢复（最多 20 个）；已不存在的文件跳过并在状态栏提示。命令行带了文件时只打开该文件，不恢复上次会话 |
| 单实例 | 程序已在运行时，再次双击 PDF / 从「打开方式」启动，会把文件转交给已运行的窗口并退出，不会出现两个进程同时改同一批文档 |
| 诊断包 | 「关于 → 导出诊断信息…」生成 zip：版本、系统与依赖、日志尾部、脱敏设置、自检结果与恢复快照数量；不含 PDF 内容与 API Key，便于反馈问题时附上 |
| 加密文档 | 打开时输入密码；搜索 / OCR / 导出自动使用该密码；另存为保持加密与原始权限 |

### 5.1 持久化设置（`%USERPROFILE%\.pdfreader\settings.json`）

| 键 | 含义 |
| --- | --- |
| `recent_files` | 最近文件（40 个，即文献库列表） |
| `window_width` / `window_height` / `window_maximized` | 窗口状态 |

## 6. 桌面文献工作流

### 6.1 段落对照翻译

入口「AI 助读 → 段落对照翻译」。选定页范围后先提取和预览，不联网；勾选要发送的段落，候选公式、参考文献与页眉页脚默认不勾选，允许手动调整。开始后源译文在同一行对照，双击行回到 PDF 原文；支持仅译文、悬停看原文、停止、重试未完成段落。

常驻显示文献、页范围、服务与模型。改变页范围后必须重新提取；运行时锁定勾选队列，停止后可改选。最终译文到达后的连接收尾不会覆盖完成结果。沿用外发确认和术语库。数字出现次数或术语译名不一致时标黄，需要人工核对。译文只保存在当前工具窗口内存中，修改文档使旧定位失效；关闭窗口清空缓存。字符量可预览，费用与耗时由服务决定，不承诺固定页数在固定时间内完成。

![段落对照翻译（合成样本）](images/0.0.6/09_parallel_translation.png)

### 6.2 阅读笔记与书目

入口「工具 → 阅读笔记」打开右侧非模态伴随面板，固定绑定创建时的标签和 Document 实例。切到另一文献不改绑；默认可读编辑，直接点击文献名/页码回原文，Alt+← 返回阅读点。关闭来源后保留草稿，首页可「返回笔记」；同路径重开不自动绑定新实例。笔记与 AI 面板互相收起时保留内容。

批注列表可展开；编辑/预览/Markdown 源码共用区域，模板、导出、素材、引用与反向链接收进「更多」。双击或拖入批注保留摘录与评论。技术标识和来源元数据随文件保存，源码可查看；既有 Markdown 无法无损转换时保留源码并说明原因，预览不改写内容。来源按文档标识、批注身份与内容/坐标指纹匹配，核对未结束、来源删除/修改、文档关闭或存在歧义时不跳转。Lumen 内保存重开可解析有效来源；复制到外部编辑器只保证文献、页码、摘录可读，自定义链接不是系统深链。

源码中可用 [[笔记名]] 打开同目录 Markdown；反向扫描最多 1000 个文件、单文件 2 MB，失败与超出范围会提示。笔记显式原子保存；收起保留草稿，「更多 → 关闭笔记」及退出应用提供保存/丢弃/取消。保存失败保留脏状态；取消退出不关闭 PDF 或停止恢复保护。笔记聚焦时 Ctrl+S/Z/Y 操作笔记，Esc 返回阅读。反向扫描未结束时等待且禁止继续编辑，防止销毁运行线程或等待期间丢失新改动。Word/PDF 使用独立导出流程，加密来源关闭后导出明文仍须确认。

「工具 → 书目引用」可提取首个 DOI、导入 BibTeX/RIS、编辑作者与期刊字段、导出 BibTeX/RIS/CSL JSON，并复制常用期刊论文的 GB/T 7714-2015、APA 7 模板或 BibTeX。Crossref 查询仅在点击按钮后发送 DOI，不发送正文。采用的标题、作者、DOI、年份保存在本机，后续打开不会被 PDF 内嵌字段覆盖。引用模板不替代投稿要求的完整 CSL 排版，请核对文献类型和缺失字段。

![阅读笔记与来源（合成样本）](images/0.0.6/10_research_notebook.png)

### 6.3 Zotero 互通

「工具 → Zotero 文献库」只读本机快照，支持合集及子合集、标题/作者/DOI 筛选、打开 PDF 并采用元数据、选择个人库或群组库的对应条目，以及书目导出。现有「开始 → Zotero 批注」仍可导入当前附件的原生批注。

「工具 → 导出批注 PDF」保存当前内存修改和嵌入批注，保留原加密，不覆盖已打开的文档。Zotero 可通过阅读器的 Import Annotations 导入外部 PDF 批注；不同版本和批注类型需核对。CSL JSON 是书目数据，不包含批注坐标；Lumen 不直接写 Zotero 数据库。

### 6.4 阅读视图

「视图 → 书本双页」将封面单独显示，后续两页并排；选择、批注、搜索与跳页按真实页码处理，布局切换保留位置。「分屏与演示」（Ctrl+Alt+S）打开两个独立视图，可选择相同或不同的已打开文档，独立翻页与滚动；页览按可见区域生成缩略图。旋转预览仅旋转显示位图，不改 PDF 的 /Rotate，旋转预览不提供编辑。

F11 直接打开全屏演示；演示中方向键、空格、PageUp/PageDown 翻页，F11 返回分屏，Esc 关闭演示窗口。

### 6.5 高级搜索与文献库全文

「工具 → 高级搜索」（Ctrl+Shift+F）：常驻显示当前文档名、页范围和匹配选项；页范围、大小写、整词、正则；逐页显示结果，双击定位。输入、范围、匹配条件或文档变化时立即清除旧结果与定位，页数变化同步收紧页范围。切到库全文时清除旧集合，禁用但保留当前文档选项，明确说明库搜索使用索引快照的短语匹配。正则每页限时，最多 10000 处结果；无文字页提示 OCR。

点击「更新当前文档的本地全文索引」并确认后，将当前文字快照写入 research.db，数据库写入在后台执行；可跨文档搜索正文并跳页，保存标签、状态和 0–5 分评分。索引为建立时快照，文档编辑后需要更新；后台事务提交期间发生编辑时，完成后明确提示保存的是旧快照、需再次更新；单篇上限 1600 万字符；加密文档拒绝写入明文索引。库搜索为短语匹配，高级选项仅用于当前文档。

「工具 → 目录与去重」监控一个选定目录，发现 PDF/EPUB 后加入本地库列表，不自动打开或上传；关闭工具窗口停止监控。重复文件按大小与 SHA-256 检查，只展示结果，不自动删除源文件。

### 6.6 长文与多文档研究

「AI 助读 → 长文与多文档」先勾选文档、指定页范围，提取并预览字符量、粗估 token 和请求次数上界，再确认联网。支持章节/图注分块、分层全文摘要、多文档方法/数据/结论/局限对比与引用矩阵、综述草稿和检索问答。请求次数有硬上限，运行时锁定文献、范围与预算。失败/停止不计为完整结果；最终答案后的连接收尾与生成区分，迟到进度不能覆盖取消或失效状态。条件/来源变化后保留旧答案并明确标为过期，旧证据定位停用。

问答默认 BM25；填写向量模型后可使用当前服务的 /embeddings 接口（服务必须支持，最多 512 个分片），不自动下载模型或切换服务。向量和结果只保存在会话内存。每处原文短引按 [d.N p.M] 核对是否出现在指定页；可定位的可双击回原文，未命中单独列明。这个检查只验证引文存在，不证明结论语义正确；没有短引的结果也会明确提示。

### 6.7 表格、公式、朗读与无障碍

「工具 → 表格提取」读取当前内存页，表格识别使用独立内存页面，保持原文修改、旋转坐标和撤销日志；可导出 Markdown/UTF-8 CSV 或发送到 AI 面板解释。合并单元格和扫描表格需人工核对。「AI 助读 → 公式转 LaTeX」框选公式，使用支持图片的模型；无法辨认符号由模型标记，结果需核对。

「视图 → 本地朗读」朗读选区或当前页，使用已安装的系统本地语音，支持分段、速度、暂停/继续和停止；缺少引擎时提示，不发送文本到 AI。「高对比度」使用黑白主题与色觉友好的批注色板。Ctrl+Shift+P 命令面板在首页和阅读器均可打开，可用键盘检索、上下选择和执行命令或子菜单项；不可用动作显示打开文档、选区、只读格式、模型或历史等前置条件，不能执行。

### 6.8 EPUB 与命令扩展

EPUB 支持文件对话框、拖放和命令行打开、渲染、选择、搜索及文本 AI 工具，保持只读，关闭保存、批注和页面编辑入口。扩展契约见 plugin_api.py：显式注册命令与读取文档摘要上下文，不自动发现、下载或执行第三方代码。

## 7. 能力边界

当前发布提供 Windows x64 安装包。原生跨平台脚本和手动构建工作流需要在对应系统成功完成测试、自检后才能提供该系统产物；不能用 Windows 测试代表 macOS/Linux 实机验证。

未提供商业代码签名、自动安装更新、云同步、移动端、DJVU/CAJ 或通用 Word→PDF 转换。翻译过滤、表格识别、公式识别和引用模板均需人工核对；不承诺跨厂商的质量、费用、翻译耗时或自动语义核验。
