## 1. 设计现状与重设计目标

### 1.1 现状

* **技术底座**：PySide6（Qt Widgets）+ Fusion 风格 + 一份全局 QSS（`theme/stylesheet.py`，按 `objectName`
  与动态属性选择器写样式）+ 自绘 SVG 线性图标（`theme/icons.py`）+ 一组令牌（`theme/palette.py`）。
* **视觉语言**（第二版设计稿 `UI/`）：暖纸底（#F6F5F1）+ 赤陶强调色（#C96A49）+ 首页墨绿导航栏与矿物色封面 +
  衬线标题（Source Serif 4）+ 无衬线正文（Inter）。浅 / 深 / 跟随系统三种主题。
* **动效**：原语 `fade_up` / `drop_in` / `pop_in` / `slide_in` / `pop_out`（退场）/ `tween`（数值补间）/
  `animate_property`，进入曲线 OutExpo、退出 InCubic。已有：选项卡弹性指示线、功能区换页横向滑入、按钮选中底色
  缩放、首页分块错开入场、卡片悬停上浮。仍没有共享元素过渡、骨架屏、列表重排动画。
* **主要问题（重设计的出发点）**：
  * 功能区按钮是 Qt 标准 `QToolButton` 图标在上文字在下，密度高、层次弱，像传统办公软件；
  * 浮层（搜索、提示、引用卡）出现方式单一，消失时没有动画（直接 `hide()`）；
  * 侧栏 / AI 面板开合只动 `maximumWidth`，内容被挤压而不是滑入；
  * 列表（批注、搜索结果、最近文件）只有入场淡入，没有增删 / 筛选过渡；
  * 状态反馈集中在状态栏左侧一行小字，存在感低，长任务（OCR、转换）用的是系统进度对话框；
  * 对话框全是系统 `QMessageBox` / `QInputDialog`，与主界面风格割裂。

### 1.2 目标（建议）

* 阅读优先：页面是主角，工具在需要时出现、不需要时退后；
* 一致的空间模型：所有浮层从「触发源」方向进入、向同方向退出；
* 动效有意义：表达因果（从哪来、到哪去）、表达状态（忙、成功、失败），而不是装饰；
* 可关闭：动效有全局开关（`motion.set_enabled`），测试与「减少动态效果」都依赖它；
* 不破坏 §24 列出的契约（信号、objectName、功能区分组名等，测试钉住了它们）。

## 4. 标题栏与功能区（Ribbon）

源码：`widgets/ribbon.py`；动作定义在 `main_window.py`。

### 4.1 标题栏（HeaderBar）

* 高 58，边距 16 / 0 / 12 / 0，元素间距 20。
* 从左到右：
  1. 品牌 `ReaderBrand`（QToolButton）：28×28 赤陶圆角方块 + 白色衬线「l.」，右接衬线 18px「lumen.」；
     悬停文字变 `accent_text`；提示「返回文献库」，点击回首页（`homeRequested`）；
  2. 选项卡按钮 `HeaderTab` ×6：开始 / 批注 / 页面 / 视图 / 工具 / AI 助读（内边距 0 / 12，选中字重 500）；
  3. `TabIndicator`：2px 强调色线，位于当前选项卡下方，左右各内缩 12；
  4. 弹性空白；
  5. 主题按钮 `HeaderIconButton`（显示目标模式图标：深色时 sun、浅色时 moon，信号 `themeToggleRequested`）；
  6. 网格按钮 `HeaderHomeButton`（grid 图标）→ 回首页；提示为当前文档名，未保存时「未保存 · 文件名」，
     无文档时「文献库」（`home_tooltip()`）。
* 「关于」移到首页页脚「关于 Lumen」。
* 动效：切换选项卡时指示线**弹性移动**——朝移动方向的领先边 320ms 先到，后随边 500ms、延迟 80ms 跟上
  （`motion.tween`，key `_ind_l` / `_ind_r`）；功能区页面 `slide_in` ±18px 360ms（随方向），组标题 `drop_in`；
  主题按钮换图标时 `drop_in` 320ms。

### 4.2 功能区主体（RibbonStack）

* 高 68。每页是若干「组」，组之间是 1px 竖分隔线（`RibbonSeparator`，上下边距 8 / 20）。
* 组：按钮横排在上，组标题 `RibbonGroupTitle` 在下；组布局边距 8, 4, 8, 2。
* 按钮 `RibbonButton`（`widgets/ribbon.py` 导出的 QToolButton 子类）：`ToolButtonTextUnderIcon`，高 46，最小宽 50，
  图标 18，圆角 8，文字 11px `text_secondary`。
  * hover：`surface_hover` 底；
  * checked：`accent_soft` 底**自绘**——勾选时 `fill` 0 → 1（420ms），底色从中心 50% 缩放到 100% 并淡入，
    取消时反向；文字 `accent_text`、图标 `icon_active`；
  * disabled：文字 `text_muted`、图标降低不透明度；
  * `danger=true` 属性：悬停时文字 `danger`、底 `danger_soft`（删除页）；
  * 带菜单（`set_menu`）：`InstantPopup`，图标右侧加 chevron_down 小箭头。
* 提示文字格式：有快捷键时 `说明  (快捷键)`（无单独说明则用按钮名），否则只显示说明。

## 11. AI 助读面板

源码：`panels/ai_panel.py`（面板）+ `panels/ai_chat.py`（对话气泡）+ `ai_assistant.py`（流程、确认、提示）。默认宽 380（可拖动 320–760），内边距 14 / 12，间距 8。
每个标签一个面板，对话互不串扰。

### 11.1 结构

1. 头部：`AiTitle`「AI 助读」+ 三个 `HeaderIconButton`（16px）：settings「模型设置」、delete_page「清空对话」、
   close「关闭面板」；
2. `AiProvider`：「服务名 · 模型 · 主机名」（本机服务显示「本机」）；未配置「未启用」；
3. `AiChip` 行（圆角 12）：
   * 「总结全文」
   * 「推荐问题」
   * 「更多 ▾」菜单：TL;DR 速览、速读高亮（当前页）、分隔线、预设动作（解释方法 / 列出贡献 / 找出局限 / 审稿意见 / 提炼术语）
   * 「框选提问」（提示「框选公式 / 图表，让 AI 解释（需要支持图片的模型）」）
4. `AiChat` 对话区：每回合右侧用户气泡（引用卡片 + 请求标题）、左侧 AI 气泡（回答 + 「复制」「存为批注」）；
   流式输出时 80ms 节流重绘最后一条；
5. 引用槽：「问 AI…」引用的原文以可关闭的折叠卡片放在输入框上方，占位改为「针对引用的内容提问…（Enter 发送）」；
6. `AiInputBox`（边距 8, 6, 6, 6）：`AiInput` 高 64，占位「就这篇文档提问…（Enter 发送，Shift+Enter 换行）」 +
   `AiSendButton` 30px 圆形（send / stop 图标，`on_accent` 色；提示「发送（Enter）」/「停止生成」）。

### 11.2 状态

| 状态 | 表现 |
| --- | --- |
| 未配置 | 空状态：AI 图标 +「让 AI 帮你读论文」+ 功能介绍 +「配置模型 →」芯片 + 隐私说明；芯片禁用 |
| 已配置、无对话 | 空状态只留标题与一段使用提示 |
| 请求中 | AI 气泡里三点跳动 +「正在请求…」→「模型思考中…」（推理模型），出字后换成正文；发送键变停止键；芯片禁用 |
| 完成 | 气泡下方「复制」，最后一条另有「存为批注」 |
| 失败 | AI 气泡内「⚠ 错误说明」（`danger` 色） |
| 已停止 | 已生成部分保留，末尾「已停止」 |
| 复制后 | 该条「复制」变「已复制」1.5s |

### 11.3 回合渲染（气泡）

* 用户气泡（右）：折叠引用卡片「选中内容 · 第 N 页 · 字数」/「框选区域 · 第 N 页」+ 一行摘要（点开看全文或截图）；
  下方是请求标题（翻译成简体中文 / 解释这段内容 / 总结全文 / TL;DR 速览 / 速读高亮 · 第 N 页 / 推荐问题 /
  提问原文 / 解释框选的图表 / 公式）。
* AI 气泡（左）：等待点阵 → Markdown 正文（或「可以接着问：」+ 可点的推荐问题）→ 错误 / 已停止 → 复制、存为批注。
* 翻译、解释、总结、TL;DR、框选与提问都写进对话历史（引用原文最多 1500 字），追问时模型知道「这段」指什么。

* 链接协议：`cite:N`（回答里的 [p.N]，点击跳页 + 闪烁定位）、`ask:i`（推荐问题）、`action:settings`（打开设置）。
* 速读高亮结果：「已在第 N 页标出 K 句要点（点下方「存为批注」可转成高亮）：」+ 列表；页面上以 accent α60 标记（z=9，不写文件）。
* 存为批注：便签内容前缀「【AI · 模型名】」；速读结果存为 K 条高亮。

### 11.4 确认与提示（ai_assistant）

确认框按钮统一「继续 / 取消」：

| 标题 | 触发 |
| --- | --- |

| 发送到 AI 服务 | 第一次向某服务发送（「将把所选内容发送到「name」（host）处理…」，带复选框「以后向该服务发送时不再询问」） |
| 加密文档 | 文档加密时外发 |
| 内容较多 | 超过 40000 字符 |
| 没有可读的文字 | 无文字层，提议先 OCR |

状态栏提示：见 §15「AI」一栏。

### 11.5 信号

`askRequested`、`actionRequested`、`captureRequested`、`stopRequested`、`settingsRequested`、`citationClicked`、
`saveNoteRequested`、`clearRequested`、`closeRequested`。

## 19. 动效清单

全部经由 `widgets/motion.py`；`motion.set_enabled(False)` 时所有动画直接跳到终值（测试默认关闭）。
退场原语 `pop_out` 已就绪（淡出 180ms 后隐藏），现有浮层尚未接入。

### 19.1 原语

| 原语 | 行为 | 默认时长 | 实现要点 |
| --- | --- | --- | --- |
| `fade_up(w, delay=, duration=)` | 不透明度 0 → 1 + 自下 8px 上移 | 500 | 挂 `QGraphicsOpacityEffect`；下一轮事件循环才读终点位置（布局未定时位置不准）；结束后移除效果 |
| `drop_in(w, duration=)` | 不透明度 0 → 1 + 自上 10px 落下 | 320 | 同上 |
| `pop_in(w, duration=)` | 不透明度 0 → 1 + 自上 4px | 320 | 同上 |
| `slide_in(w, dx, duration=)` | 不透明度 0 → 1 + 自横向 dx 滑入 | 360 | 同上 |
| `pop_out(w, duration=, on_done=)` | 不透明度 1 → 0，结束后隐藏 | 180 | InCubic；动效关闭或已隐藏时立即收尾 |
| `tween(owner, start, end, duration, on_value, *, delay, easing, key)` | 数值插值回调 | — | 同 owner + key 的上一段被打断并释放；有 delay 时先回调起点 |
| `animate_property(target, prop, start, end, duration, owner=)` | 任意 Qt 属性补间 | — | 同一 owner 上的新动画会停掉旧动画 |
| 曲线 | 进入 OutExpo / 退出 InCubic | — | |

## 24. 重设计必须保持的契约

1. **分层铁律**（见 [02_架构设计](02_架构设计.md)）：界面只在 `gui/`；不在 `gui/` 外引入 Qt；页面渲染在主线程。
2. **颜色只走令牌**：新增颜色先进 `Palette`（浅深两套都要给），QSS 与自绘代码引用令牌。
3. **动效走 `motion`**：新增动画必须遵守 `motion.enabled()`；关闭时直接到终态，不留中间态。测试依赖这个开关。
4. **功能区选项卡与组名被测试钉住**：开始 / 批注 / 页面 / 视图 / 工具 / AI 助读，以及 §4.3 每个组的名称与按钮顺序。
   改名或调整需同步修改测试。
5. **动作对象是唯一入口**：按钮、菜单、快捷键共用同一个 `QAction`（启用 / 勾选状态自动同步）。换外观不要绕过 QAction。
6. **objectName 与动态属性**：QSS 和测试按 objectName 查控件（`RibbonButton`、`HeaderTab`、`DocTabs`、`SearchPanel`、
   `ToolHint`、`CitePopover`、`AiChip`、`AiSendButton`、`StatusMessage`、`ModeChip`、`ReaderBrand`、`HeaderHomeButton`、
   `LibraryRoot`、`BookCard`、`QuietImport`、`FilterChip`、
   `AnnotList`、`ThumbList`、`TocTree`、`BookmarkList` 等）。替换控件时保留名字或同步改测试。
7. **信号接口**：§7.4、§8.5、§9、§11.5、§12 列出的信号是主窗口与控件之间的契约；多标签下主窗口用 `_for_tab`
   过滤非当前标签的信号——新控件若是每标签一份，也要走这条路径。
8. **坐标与文本**：页面叠加层坐标一律「可见帧」（已应用旋转）；不要在 GUI 里直接调 PyMuPDF。
9. **键盘可达**：所有快捷键（§18）与 Esc 顺序保持不变。
10. **隐私**：AI 外发确认（§11.4）不可去掉或默认跳过。

## 25. 高级动效改造建议

以下是基于现有结构可落地的方向，供设计取舍（不是现状）。

### 25.1 动效系统

* 在 `TOKENS` 中把时长分级：`instant` 100 / `fast` 200 / `base` 320 / `slow` 500，曲线分「进入 OutExpo / OutCubic」
  「退出 InCubic」「强调 OutBack」三类；
* `motion` 增加 `fade_out` / `rise_out` 等**退场原语**（动画结束再 `hide()`），并支持「打断后从当前值继续」；
* 增加 `stagger(widgets, step)` 统一列表入场；
* 尊重系统「减少动态效果」：Windows 上读 `SPI_GETCLIENTAREAANIMATION`，映射到 `motion.set_enabled`。

### 25.2 结构性过渡

* **侧栏 / AI 面板**：从「挤压宽度」改为「内容滑入 + 阅读区平滑让位」——面板内容整体平移 + 淡入，阅读区在动画结束后
  再重算适宽，避免每帧重排；
* **首页 → 文档**：被点的封面放大为页面卡片（共享元素感），或首页淡出上移、阅读区自下浮入；
* **标签切换**：旧视图淡出 120ms、新视图淡入 200ms；新增标签从右侧展开宽度，关闭时收拢；

### 25.3 微交互

* 功能区按钮：按下缩放 0.96、松开回弹（选中底色从中心扩散已实现）；
* 高亮色板：选色时色块放大 + 勾选标记描边动画；光标与工具提示圆点同步过渡颜色；
* 批注生成：松手瞬间高亮从左到右「刷」出（200ms），侧栏批注数徽标跳动一次，新卡片插入时其他卡片下推；
* 书签添加：书签图标沿弧线飞向侧栏书签列表；
* 数字：页码、缩放百分比、搜索计数、批注数使用滚动数字过渡。

### 25.4 反馈与加载

* 状态栏消息升级为分级 Toast（成功 / 提示 / 警告 / 失败），从底部浮起，可堆叠；
* OCR / 转换 / 打印渲染改为非模态进度胶囊（状态栏或右下角），完成时变成可点击的结果入口；
* 页面占位改为骨架闪光（shimmer），渲染完成交叉淡入；缩略图同理；
* AI 面板：「思考中」用呼吸点或流光；流式文字逐段淡入；引用 [p.N] 悬停时预览对应页缩略图；
* 搜索：命中数递增动画；结果列表随输入平滑重排；
* 拖文件进窗口：阅读器里出现半透明投放层；首页导入区描边流动。

### 25.5 主题与阅读模式

* 主题切换：以主题按钮为圆心的圆形揭示（截图旧界面覆盖其上，再以扩大的圆形遮罩露出新界面）；
* 阅读模式：页面滤镜强度 0 → 1 过渡 300ms（重绘成本高，可只对可见页做）。

### 25.6 实现注意

* Qt Widgets 一个控件只能挂一个 `QGraphicsEffect`：阴影 + 透明度需拆到父子两层，或用 `paintEvent` 自绘；
* 大面积 `QGraphicsOpacityEffect` 会强制离屏渲染，阅读区不要整体套透明度，优先动场景项（`QGraphicsItem.setOpacity`）；
* 动画期间避免触发页面重渲染（缩放、适宽在动画结束后统一做一次）；
* 所有新动画都要在 `motion.enabled() == False` 时直达终态，并补测试断言终态。
