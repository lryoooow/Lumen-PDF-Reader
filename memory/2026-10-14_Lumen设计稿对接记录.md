## 与设计稿的有意差异（均为保证功能完整）

1. 「文件」组额外保留**另存为 / 关闭**按钮（设计稿无可见入口，仅靠快捷键不可接受）。
2. 「原大」只保留 Ctrl+1 快捷键（与设计稿一致不放按钮）。
3. 「翻译」按钮如设计稿所示提示「翻译插件尚未配置」——需要在线服务与 API Key，待用户决定。
4. 主题切换只保留浅 / 深色开关（设计稿）；设置里原有的 `system` 模式仍可被旧配置读取。
5. 品牌名 Lumen 只用于界面显示；安装包 / exe 名仍为 PDFReader（改名涉及安装路径与注册表，需用户确认）。

## 对接中发现并修复的缺陷（均有回归测试）

- 浮层以 lambda 连接全局主题信号 → 窗口销毁后切主题访问已释放对象（改绑定方法）。
- 页面淡入动画期间项被移除 → RuntimeError（动画回调捕获后自动停止）。
- 调整窗口后立刻拖动缩放滑杆被待执行的适宽重排改回（滑杆记住用户值；手动缩放取消适配定时器）。
- 「[1].」等带标点的引用识别不到；中文部分高亮的批注原文提取为空（改用拆字后的词表）。
- 视觉验收发现：缩略图单列、下拉标记字形缺失（改 SVG chevron）、模式标签被拉高、
  搜索浮层落回左上（先定位后动画）、适宽出现横向滚动条、批注角标不刷新、关闭浮层焦点丢失。
