# 项目结构

> 适用版本：Lumen 0.0.6 当前开发分支。按仓库中的实际文件整理（2026-10-22）。分层规则见 [02_架构设计](02_架构设计.md)。

## 1. 根目录

```
PDF Reader/
├── src/pdfreader/        源码（Python 包名 pdfreader）
├── tests/                测试（unit / integration / fixtures）
├── docs/                 文档（本目录）与截图 docs/images/
├── scripts/              打包、图标、测试样例生成、界面截图脚本
├── dist/                 打包产物（不入库）
├── pyproject.toml        项目元数据、依赖、ruff / mypy / pytest / coverage 配置
├── uv.lock               依赖锁定
├── Makefile              常用命令
├── AGENTS.md / CLAUDE.md 协作约束（CLAUDE.md 只指向 AGENTS.md）
├── CHANGELOG.md          变更记录（Keep a Changelog）
├── README.md
└── LICENSE               AGPL-3.0
```

## 2. 源码 `src/pdfreader/`

```
pdfreader/
├── __init__.py              版本号 __version__
├── __main__.py              python -m pdfreader
├── main.py                  应用入口：QApplication、单实例转交、全局异常钩子、命令行打开文件、--selftest
│
├── engines/                 引擎层（唯一 import pymupdf 的地方）
│   ├── base.py              PdfEngine 协议（坐标一律可见帧）
│   ├── pdf_engine.py        PyMuPDF 实现：打开 / 渲染 / 取词 / 搜索 / 编辑 / 批注 / 目录链接 / 保存
│   ├── types.py             不可变值对象：Rect、WordBox、SearchHit、Annotation、TocEntry、LinkInfo …
│   └── exceptions.py        FileOpenError、PasswordRequiredError、CorruptPdfError …
│
├── core/                    领域模型（纯 Python）
│   ├── document.py          Document：修改状态、撤销保存点、页数同步、密码
│   └── page.py              Page：页文本懒加载缓存
│
├── controllers/
│   ├── document_controller.py   文档操作统一入口；last_error；摘录 / 链接文字等只读查询
│   └── annotation_controller.py 工具模式状态机（选择 / 抓手 / 高亮 / 下划线 / 手写 / 便签 / 文本框 / 橡皮擦 / 签名 / 时间 / 框选）
│
├── services/                纯 Python 服务（经引擎访问 PDF）
│   ├── converter.py         PDF → PNG / JPEG / TXT / Word / Excel；图片 → PDF
│   ├── ocr.py               RapidOCR 封装（懒加载，依赖缺失时报 OcrError）
│   ├── notes.py             批注 → Markdown 笔记
│   ├── dictionary.py        离线英汉词典（ECDICT 精简版，只读 SQLite）
│   ├── materials.py         写作素材库：单词本 / 语料 / 引文 / 术语（~/.pdfreader/materials.db）
│   ├── recovery.py          崩溃恢复快照：整份 PDF + JSON 清单、会话锁、备份与恢复副本（~/.pdfreader/recovery）
│   ├── diagnostics.py       诊断包：脱敏设置 / 日志尾部 / 环境与依赖版本（zip，不含文档内容）
│   ├── zotero.py            只读 Zotero 库：合集 / 条目 / PDF 附件 / 批注（拷贝快照后读）
│   └── ai/                  AI 助读（OpenAI 兼容）
│       ├── provider.py      厂商预设、ProviderConfig / AiSettings、ai.json 读写
│       ├── keystore.py      API Key ↔ 系统凭据管理器（keyring）
│       ├── client.py        ChatClient：流式对话、列模型、取消、错误中文化
│       ├── context.py       分块、BM25 检索、全文概览、[p.N] 链接化
│       ├── textfix.py       回答显示前整理：LaTeX → Unicode、中文语境全角标点、中文加粗转 <b>
│       ├── prompts.py       翻译 / 解释 / 总结 / TL;DR / 问答 / 推荐问题 / 速读 / 看图 提示词与预设动作
│       └── speedread.py     速读高亮：按词切句（附行矩形）、建议句数
│
├── workers/                 QThread 后台任务
│   ├── search_worker.py     全文搜索（可取消）
│   ├── ocr_worker.py        OCR（逐页、可取消、长边限幅）；ImageOcrWorker 识别单张截图
│   ├── convert_worker.py    格式转换
│   └── ai_worker.py         AI 请求（流式增量 / 列模型，可取消）
│
├── gui/
│   ├── main_window.py       主窗口：动作、布局、接线、标签切换 / 关闭、快照、导航历史、阅读位置
│   ├── document_tab.py      文档标签：一份文档及只属于它的控制器 / 视图 / AI / 历史 / OCR 状态
│   ├── single_instance.py   单实例：QLocalServer / QLocalSocket 把第二次启动的文件转交已运行窗口
│   ├── ai_assistant.py      AI 助读编排：外发确认、取文字拼消息、请求生命周期、存为批注
│   ├── selection_translator.py  划词翻译：「译」按钮 / 选中即译、连翻、乱码 → 截图识别、查词与收藏
│   ├── widgets/
│   │   ├── pdf_view.py      阅读视图：渲染回填、选择、批注预览、链接、阅读模式、平滑滚动 / 脉冲
│   │   ├── library.py       文献库首页（导航 / 继续阅读 / AI 助读卡 / 筛选搜索 / 文档卡片 / 响应式断点）
│   │   ├── ribbon.py        标题栏（品牌 / 弹性指示线选项卡 / 主题 / 回首页）+ 分组功能区
│   │   ├── doc_tabs.py      文档标签栏（文件图标、拖动排序、中键关闭、右键「关闭其他」）
│   │   ├── status_bar.py    状态栏：翻页、阅读进度、消息、模式标签、缩放滑杆
│   │   ├── overlays.py      工具提示胶囊、参考文献预览卡
│   │   ├── panel_grip.py    两侧栏的宽度拖动条
│   │   ├── translate_popup.py  划词翻译的「译」按钮、译文浮窗（可拖动、钉住、连翻）与词卡
│   │   └── motion.py        动效工具（fade_up / drop_in / pop_in / slide_in / tween）
│   ├── panels/
│   │   ├── sidebar.py       侧边栏：目录 / 批注卡片（搜索与筛选） / 缩略图 / 素材库
│   │   ├── search_panel.py  搜索浮层
│   │   ├── ai_panel.py      右侧 AI 助读面板（预设动作、输入框、引用卡片）
│   │   └── ai_chat.py       AI 对话视图：左右气泡、折叠引用卡片、Markdown 着色
│   ├── dialogs/             导出、OCR 结果、签名、关于、AI 模型设置
│   └── theme/               palette.py（令牌）、stylesheet.py（QSS）、icons.py（SVG 图标）、manager.py
│
├── config/settings.py       用户设置（类型校验、原子写入、阅读位置、书签）
├── utils/                   logger.py、cache.py（LRU）、text.py（CJK / 去换行 / 连字 / 乱码判定）、qt_bridge.py（位图转换）
└── resources/
    ├── icons/app.ico        应用图标（scripts/make_icon.py 生成）
    └── dict/ecdict-lite.db  离线词典（scripts/build_dictionary.py 由 ECDICT 生成，MIT）
```

├── fixtures/samples/        样例 PDF（scripts/download_samples.py 可重新生成）
│                            simple_text、with_annotations、with_tables、scanned、rotated、encrypted、corrupt、empty
├── integration/test_open_render.py   打开 → 渲染 → 编辑 → 保存的端到端流程
└── unit/
    ├── test_layering.py     分层铁律（AST 扫描）
    ├── test_package.py / test_settings.py
    ├── engines/             引擎：基础、编辑、批注、加密保存、旋转页、科研功能（中文取词 / 标记 / 目录链接 / 水印 / 保存）
    ├── core/                Document：基础、编辑、安全（保存点 / 删页 / 密码）
    ├── controllers/         文档控制器、批注模式
    ├── services/            转换、OCR、笔记导出、离线词典、写作素材库、崩溃恢复、诊断包、Zotero 只读库
    ├── workers/             搜索、OCR（整页 / 截图）、转换线程
    ├── utils/               LRU 缓存、文本工具
    └── gui/                 主窗口（基础 / 端到端流程 / 启动会话）、视图（基础 / 导航 / 选择手势）、单实例、
                             侧边栏、搜索浮层、导出对话框、主题、诊断导出、
                             test_lumen_ui.py（设计稿逐项对接）、划词翻译与词卡、素材页、Zotero 批注导入、自动保存 / 崩溃恢复

## 4. 脚本 `scripts/`

| 文件 | 用途 |
| --- | --- |
| `build_windows.py` | PyInstaller onedir 打包；`--installer` 再用 NSIS 生成安装程序 |
| `build_dictionary.py` | 由 ECDICT 生成精简版离线词典 `resources/dict/ecdict-lite.db`（MIT，约 15 万词） |
| `installer.nsi` | NSIS 安装脚本（快捷方式、卸载、「打开方式」注册） |
| `make_icon.py` | 由内置 logo SVG 生成多尺寸 `app.ico` |
| `download_samples.py` | 生成测试样例 PDF |
| `capture_screenshots.py` | 离屏渲染 Lumen 各界面状态截图（视觉验收、`docs/images/`） |

## 5. 桌面研究模块

| 位置 | 职责 |
| --- | --- |
| core/layout.py | 单页/书本排版的纯几何计算 |

| services/notebook.py | 笔记来源、隐藏元数据、双链/反向链接、原子保存与 DOCX |
| services/bibliography.py | DOI/Crossref、BibTeX/RIS/CSL JSON 与引用模板 |
| services/text_search.py、research_library.py、library_files.py | 正则超时、FTS5 事务与文件发现/哈希检查 |
| services/ai/research.py、semantic.py | 章节分块、分层摘要、短引核对和向量检索 |
| services/tables.py、engines/types.TableData | 表格导出和引擎中立数据 |
| gui/dialogs/translation_dialog.py、notebook_dialog.py、bibliography_dialog.py | 对照翻译、可嵌入 NotebookPanel / 独立笔记宿主、书目界面 |
| gui/dialogs/research_search_dialog.py、library_files_dialog.py、zotero_library_dialog.py | 全文搜索、目录检查、只读 Zotero |
| gui/dialogs/research_dialog.py、table_dialog.py、reading_workspace.py、speech_dialog.py | 长文研究、表格、分屏与朗读 |
| gui/dialogs/command_palette.py、plugin_api.py | 键盘命令与显式命令扩展契约 |
| workers/research_worker.py、metadata_worker.py、library_worker.py、notebook_worker.py | 纯网络、SQLite/文件 I/O 与反向链接线程 |
| scripts/build_desktop.py、ci_native_build_linux.sh | 原生目录包与 CI 系统凭据服务 |
| .github/workflows/build-desktop.yml | 手动触发的 Windows/Linux/macOS 构建与冻结自检 |
