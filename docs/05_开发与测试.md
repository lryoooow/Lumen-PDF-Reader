# 开发与测试

> 适用版本：Lumen 0.0.6 当前开发分支。协作约束以仓库根目录 [AGENTS.md](../AGENTS.md) 为准，本文是具体操作说明。

## 1. 环境

* Python 3.13（`requires-python >= 3.10`，mypy 按 3.10 检查）
* [uv](https://docs.astral.sh/uv/) 管理依赖：`uv sync` 安装运行与开发依赖（`[dependency-groups] dev`）
* Windows 为主要目标平台；Linux 下 GUI 测试使用 xvfb

```bash
uv sync
make install      # 安装 pre-commit 钩子（可选）
make run          # 启动应用（uv run pdfreader）
```

## 2. 常用命令（`make help` 查看全部）

| 命令 | 作用 |
| --- | --- |
| `make check` | 提交前全套检查：`ruff check` → `ruff format --check` → `mypy` → `pytest` |
| `make test` / `make test-fast` | 测试（含 / 不含覆盖率） |
| `make lint` / `make format` / `make typecheck` | 单项检查 / 格式化 |
| `make samples` | 重新生成 `tests/fixtures/samples/` 的样例 PDF |
| `make icon` / `make build` / `make installer` | 生成图标 / 打包 / 生成安装程序（见 [06_打包与发布](06_打包与发布.md)） |
| `make clean` | 清理缓存与打包中间产物（保留 `dist/`）；`make clean-dist` 删除打包产物 |

## 3. 质量门禁

| 项 | 要求 |
| --- | --- |
| ruff | `ruff check .` 与 `ruff format --check .` 无问题（规则见 `pyproject.toml`） |
| mypy | strict 模式无错误；不用 `type: ignore` 掩盖设计问题（测试中针对第三方库的少量 ignore 可接受） |
| pytest | 全部通过；`filterwarnings = error`（警告即失败） |
| 覆盖率 | ≥ 75%（`[tool.coverage.report] fail_under`），修改低覆盖区域时同步上调 |
| 分层 | `tests/unit/test_layering.py` 强制三条铁律（见 [02_架构设计](02_架构设计.md)） |

## 4. 测试约定

* **位置**：`tests/unit/<层>/` 与源码分层一一对应；端到端流程放 `tests/integration/`。按主题命名测试文件，
  不按「第几轮修复」命名。
* **GUI**：使用 pytest-qt 的 `qtbot`。`tests/conftest.py` 默认：
  * 把用户设置重定向到临时目录（测试不读写真实的 `~/.pdfreader/settings.json`）；
  * 关闭界面动效（`motion.set_enabled(False)`），断言针对最终状态；测动效的用例自行打开。
  * 用例收尾时显式处理 Qt `DeferredDelete`：测试没有常驻 `app.exec()`，单独调用 `processEvents()`
    不保证兑现 `deleteLater()`，否则隐藏窗口与动画会跨用例积累，导致整套验证慢化或原生对象析构异常。
* **样例**：`tests/fixtures/samples/` 下 8 个 PDF（含 `encrypted.pdf`，密码 `secret`；`rotated.pdf` 为 /Rotate=90）。
  需要其他形态时在测试里用 PyMuPDF 临时生成（测试可以 import pymupdf，铁律只约束 `src/`）。
* **缺陷修复**：先写能稳定复现的测试，再修；不得修改断言目标、削弱或删除测试来通过。
* **环境性失败**：可用内存不足导致 ONNXRuntime `bad allocation`、剪贴板被其他进程占用等，应显式 `skip` 并写明原因。
* **坐标相关改动**必须跑 `tests/unit/engines/test_rotated_pages.py`。

## 5. 视觉验收

自动化测试只验证接线与状态。改动界面后，运行截图脚本生成各状态截图，与设计稿人工比对：

```bash
uv run python scripts/capture_screenshots.py <输出目录>
```

脚本以离屏模式渲染，并通过 `QT_QPA_FONTDIR=C:/Windows/Fonts` 使用系统字体，中文显示与真机一致。

## 6. 本地 `memory/` 目录

排查过程中的分析记录、复现脚本、一次性探针放在根目录 `memory/`。该目录已加入 `.gitignore`，**不入库**：

* 报告：`YYYY-MM-DD_主题.md`（中文文件名）；复现脚本 `repro_*.py`；探针 `_probe_*.py`；
* 有长期价值的结论要沉淀下来——复现脚本转成 `tests/` 里的回归测试，机制写进 `docs/`，变更写进 `CHANGELOG.md`。

## 7. 版本与变更记录

* 版本号三处同步：`pyproject.toml`、`src/pdfreader/__init__.py`、`scripts/installer.nsi`（`tests/unit/test_package.py` 校验前两处一致）。
* 每次发布在 `CHANGELOG.md` 写对应条目（Keep a Changelog 格式）；开发中的改动写在 `[Unreleased]`。

## 8. 桌面研究回归

新增测试覆盖段落聚合/列顺序、数字计数、译文缓存失效、限流重试、笔记来源与文档隔离、元数据隐藏及 Word/PDF 中文输出、BibTeX/RIS 往返、Crossref MockTransport、Zotero 合集/群组 URI、高级搜索与恶意正则超时、FTS 中文与事务更新、加密拒绝索引、目录发现/只读哈希检查、书本右页命中、分屏/旋转不改文档、EPUB 只读、分层摘要全分片覆盖、请求预算、向量校验、短引核对、本地朗读队列和命令扩展。

AI/Crossref 测试只用 MockTransport；朗读用 QObject 替身。原生双击事件已由 Qt 识别，不能因应用处理延迟把它降为单击，回归测试不依赖真实计时抖动。

跨平台工作流是手动触发的原生构建与核心测试；发布时分别记录各平台结果，不将配置存在写成实机通过。

### 可用性与任务上下文回归

功能区溢出与键盘可达见 `test_ribbon_accessibility.py`，主题活动文字对比度见 `test_theme_contrast.py`。`test_notebook_workspace.py` 覆盖真实主窗的并排笔记、来源实例、鼠标回源、文稿保真、快捷键与异步关闭；`test_ocr_context.py` 通过排队信号验证旧任务隔离、失败页和取消重试；`test_task_state.py` 用 MockTransport 与连接收尾屏障验证翻译/研究状态。测试不联网，不把返回文字视为线程已结束。视觉截图使用合成文献，逻辑窗口尺寸、DPR 和实际系统显示设置需分别记录；Qt 模拟缩放不替代 Windows 实际缩放验收。
